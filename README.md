# AI Job Intelligence Platform

## Project Overview
An AI-powered platform that helps users find suitable jobs based on their resume skills.

## Features
- Resume skill extraction
- Job listings from a database
- Skill-based job recommendations
- Job search and matching

## Technology Stack
- **Frontend:** React, CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Data Processing:** Pandas, NLP

## Project Workflow
Resume Upload → Skill Extraction → Job Matching → Recommended Jobs

## Future Enhancements
- Machine learning-based job recommendations
- Skill gap analysis
- Career recommendations
